# Roadmap

## Phase 1 — MVP Website (In Progress)
**Goal:** Complete, beautiful, production-ready static website

- [x] Project scaffold & configuration
- [x] Brand design system (colors, fonts, tokens)
- [x] Data layer (products, categories, locations, testimonials)
- [x] Layout components (Navbar, Footer, MobileBottomNav)
- [ ] Homepage (Hero, Featured, Occasions, Brand Story, Testimonials, Locations)
- [ ] Menu page with category filters
- [ ] About page
- [ ] Locations page
- [ ] Contact/Order page
- [ ] Mobile responsiveness verified
- [ ] Performance check (images optimized, fast load)

## Phase 2 — Backend & Admin (~1-2 months post-launch)
**Goal:** Dynamic content management, real order inquiries captured

- [ ] Supabase project setup
- [ ] Products table + admin CRUD
- [ ] Contact form → Supabase (order inquiries saved to DB)
- [ ] Email notifications via Resend or Supabase Edge Functions
- [ ] Admin dashboard (protected route)
- [ ] Image upload via Supabase Storage

## Phase 3 — Growth Features (~3-6 months)
**Goal:** Increase conversions and customer engagement

- [ ] Customer accounts (Supabase Auth)
- [ ] Order history
- [ ] WhatsApp integration for quick ordering
- [ ] Google Maps embeds on location cards
- [ ] SEO: structured data, meta images, sitemaps
- [ ] Analytics (Vercel Analytics or Posthog)

## Phase 4 — E-Commerce (~6-12 months)
**Goal:** Full online ordering capability

- [ ] Shopping cart
- [ ] Checkout flow
- [ ] Payment gateway (GCash, Maya, credit card)
- [ ] Order management system
- [ ] Delivery tracking integration
